B41M12 — Kahoot: οδηγίες καθηγητή

Εισαγωγή: Kahoot → Create → Add question → Import → Import spreadsheet. Επιλέξτε το αντίστοιχο XLSX.
4 standard Quiz questions. Μία σωστή απάντηση ανά ερώτηση. Χωρίς premium τύπους ερωτήσεων.
Εικόνες: προσθέστε χειροκίνητα a στην ερώτηση 1, b στη 2, c στη 3 και d στη 4.
Οι εικόνες είναι πραγματικά παραδείγματα/στιγμιότυπα Microsoft Support. Οι εκδόσεις του Excel μπορεί να διαφέρουν από το βιβλίο.
Δεν απαιτείται η εικόνα για την απάντηση. Η αρχική επισήμανση εντολών της Microsoft μπορεί να δίνει οπτική βοήθεια.
Η τετράδα είναι σύντομος διαγνωστικός έλεγχος επιλεγμένων βασικών στόχων, όχι πλήρης πρακτική αξιολόγηση όλου του κεφαλαίου.

1. Θέλεις κείμενο στο κέντρο του κελιού, οριζόντια και κατακόρυφα. Τι επιλέγεις;
Σωστή απάντηση: 3 — Center + Middle Align
Δείκτης Επιτυχίας: Β4.4.4 | Δείκτης Επάρκειας: Β4.4.2
Οριζόντια και κατακόρυφη στοίχιση. Center + Middle Align.
Εικόνα: B41M12-a.png
Πηγή σελίδας: https://support.microsoft.com/en-us/excel/align-text-in-a-cell-in-excel
Αρχική εικόνα: https://support.microsoft.com/en-us/excel/media/xlweb-alignmenttext.png

2. Τα A3:A5 είναι ενωμένα. Θέλεις ξανά τρία ξεχωριστά κελιά. Ποια εντολή χρησιμοποιείς;
Σωστή απάντηση: 1 — Unmerge Cells
Δείκτης Επιτυχίας: Β4.4.5 | Δείκτης Επάρκειας: Β4.4.3
Unmerge Cells: τα A3:A5 γίνονται ξεχωριστά. Το κείμενο μένει στο A3.
Εικόνα: B41M12-b.png
Πηγή σελίδας: https://support.microsoft.com/en-us/excel/get-started/merge-and-unmerge-cells-in-excel
Αρχική εικόνα: https://support.microsoft.com/en-us/excel/media/before-and-after-unmerge.jpg

3. Το Wrap Text κόβεται σε ύψος. Κρατάς ίδιο Font Size και Column Width. Τι κάνεις;
Σωστή απάντηση: 4 — Αυξάνεις το Row Height
Δείκτης Επιτυχίας: Β4.4.7 | Δείκτης Επάρκειας: Β4.4.5
Αύξηση Row Height: εμφανίζονται οι γραμμές του Wrap Text χωρίς αλλαγή πλάτους ή γραμματοσειράς.
Εικόνα: B41M12-c.png
Πηγή σελίδας: https://support.microsoft.com/en-us/excel/wrap-text-in-a-cell-in-excel
Αρχική εικόνα: https://support.microsoft.com/en-us/excel/media/alignment-wrap-text-png.png

4. Στο B2:D5 θέλεις περίγραμμα γύρω από ΚΑΘΕ κελί, μέσα και έξω. Ποια επιλογή βάζεις;
Σωστή απάντηση: 2 — All Borders
Δείκτης Επιτυχίας: Β4.4.8 | Δείκτης Επάρκειας: Β4.4.8
All Borders: εξωτερικά και εσωτερικά περιγράμματα της περιοχής.
