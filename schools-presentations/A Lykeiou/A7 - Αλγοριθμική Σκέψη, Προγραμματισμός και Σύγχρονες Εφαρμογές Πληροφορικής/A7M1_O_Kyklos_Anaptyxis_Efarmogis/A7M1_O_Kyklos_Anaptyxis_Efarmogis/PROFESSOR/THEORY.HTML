Σχεδιασμός και έλεγχοςDesign and testing

Μια σωστή εφαρμογή δεν ξεκινά από τον κώδικα. Πρώτα καταλαβαίνουμε το πρόβλημα και σχεδιάζουμε τη λύση.A correct application does not start with code. First we understand the problem and design the solution.

Ένας κύκλος που επαναλαμβάνεταιA cycle that repeats

2 · Σχεδιάζουμε τον αλγόριθμο2 · We design the algorithm

ΑλγόριθμοςAlgorithm

Μια ολοκληρωμένη σειρά από βήματα ή ενέργειες που απαιτούνται για την επίλυση ενός προβλήματος.A complete series of steps or actions needed to solve a problem.

Τρεις τρόποι έκφρασηςThree ways to express it

Λεκτική περιγραφή, ψευδοκώδικας και λογικό διάγραμμα. Πριν τον μετατρέψουμε σε πρόγραμμα, ελέγχουμε αν δίνει σωστά αποτελέσματα.Verbal description, pseudocode and flowchart. Before we turn it into a program, we check that it gives correct results.

Λεκτική περιγραφήVerbal description

Διάβασε έναν αριθμό. Υπολόγισε το τριπλάσιό του. Εμφάνισε το αποτέλεσμα.Read a number. Calculate three times that number. Display the result.

ΨευδοκώδικαςPseudocode

ΔΙΑΒΑΣΕ x
y ← 3 * x
ΓΡΑΨΕ y
READ x
y ← 3 * x
WRITE y

Γεωμετρικά σύμβολαGeometric symbols

3 · Μετατρέπουμε σε πρόγραμμα3 · We convert into a program

ΠρόγραμμαProgram

Ακολουθία εντολών (κώδικας) σε γλώσσα προγραμματισμού, σε λογική σειρά και συγκεκριμένη σύνταξη. Αντιστοιχεί σε κάποιον αλγόριθμο.A sequence of commands (code) in a programming language, in logical order and with specific syntax. It matches an algorithm.

Γλώσσα προγραμματισμούProgramming language

Τεχνητή γλώσσα με την οποία μετατρέπουμε έναν αλγόριθμο σε πρόγραμμα, ώστε να τον εκτελεί ο υπολογιστής.An artificial language we use to turn an algorithm into a program, so the computer can run it.

4 · Ελέγχουμε και διορθώνουμε4 · We test and correct

Το λάθοςThe mistake

Γράψαμε y = x + 3. Για x = 3 εμφανίζει 6 αντί για 9.We wrote y = x + 3. For x = 3 it displays 6 instead of 9.

Η διόρθωσηThe fix

Διορθώνουμε σε y = 3 * x και επαναλαμβάνουμε όλες τις δοκιμές.We correct it to y = 3 * x and repeat all the tests.

Το πρόγραμμα τρέχει χωρίς μήνυμα σφάλματος, αλλά τα αποτελέσματα είναι λάθος.The program runs with no error message, but the results are wrong.

💬 ΣυζήτησηDiscussionΑν δοκιμάζαμε μόνο το x = 0, θα αρκούσε για να βεβαιωθούμε ότι το πρόγραμμα είναι σωστό;If we tested only x = 0, would that be enough to be sure the program is correct?Όχι. Μία δοκιμή δεν αρκεί. Επιλέγουμε διαφορετικές τιμές και συγκρίνουμε με τα αναμενόμενα αποτελέσματα.No. One test is not enough. We choose different values and compare them with the expected results.

Μετατροπή νομισμάτωνCurrency conversion

euro=float(input())
dollars=euro*1.29
pounds=euro*0.86
print('%.2f' % dollars)
print('%.2f' % pounds)

Οι ισοτιμίες 1.29 και 0.86 είναι δεδομένα του παραδείγματος του βιβλίου.The exchange rates 1.29 and 0.86 are data from the book's example.
