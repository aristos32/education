A7 Interactive Lessons and Kahoots

HTML:
- Open html/index.html in Chrome, Edge or Firefox.
- Every lesson is self-contained and works offline.
- Each lesson has 8 screens: short theory for about 10 minutes, an animated walkthrough, text-based Python code, quiz and workbook activities.
- The theory capsules were cross-checked with the official A7 theory book.
- Arrow keys navigate; F toggles full screen; P plays the animated flow.

Kahoot:
- Upload each .xlsx with Create > Import spreadsheet.
- Questions use only standard Quiz type.
- Add the matching image A7Mx-a ... A7Mx-j manually.

Images:
- image_sources.csv records the original page and image URL.
