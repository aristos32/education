Sentinel

Ειδική value που δηλώνει τέλος και δεν είναι κανονικό data.

Priming read

x = int(input())
total = 0
count = 0
while x != 999:
    total += x
    count += 1
    x = int(input())
if count > 0:
    print(total / count)

Δοκιμή εκτέλεσης

Η sentinel 999 δεν προστίθεται στο total ούτε στο count.
