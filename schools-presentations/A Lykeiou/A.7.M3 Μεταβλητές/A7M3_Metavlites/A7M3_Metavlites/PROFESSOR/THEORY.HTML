Τι είναι μεταβλητή;What is a variable?

Ένα «κουτί» με όνομαA box with a name

Μια μεταβλητή έχει όνομα και περιέχει μια τιμή, η οποία μπορεί να αλλάζει κατά τη διάρκεια εκτέλεσης του προγράμματος.A variable has a name and holds a value, which can change while the program runs.

Δημιουργία με εκχώρησηCreated by assignment

Στην Python δεν δηλώνουμε τις μεταβλητές: τις δημιουργούμε δίνοντάς τους τιμή. μεταβλητή = έκφραση, π.χ. plevra = 4In Python we don't declare variables: we create them by giving them a value. variable = expression, e.g. plevra = 4

Κανόνες ονομασίαςNaming rules

Τι επιτρέπεταιWhat is allowed

Γράμματα, ψηφία και κάτω παύλα (_). Το όνομα ξεκινά με γράμμα ή με κάτω παύλα.Letters, digits and the underscore (_). The name starts with a letter or an underscore.

Τι δεν επιτρέπεταιWhat is not allowed

Να ξεκινά με αριθμό, να έχει κενά, παύλες (-), παρενθέσεις ή άλλα σύμβολα.Starting with a digit, spaces, hyphens (-), brackets or other symbols.

✓ MyName✓ _number✓ Num1✓ NAME_SURNAME✗ 2Lessons✗ My Name✗ Name-Surname✗ My(Name)

Συνηθίζουμε ονόματα σχετικά με το περιεχόμενο, π.χ. perimetros, mesos_oros.We usually choose names related to the content, e.g. perimetros, mesos_oros.

💬 ΣυζήτησηDiscussionΓιατί το 2Lessons δεν είναι αποδεκτό, ενώ το Lessons2 είναι;Why is 2Lessons not allowed, while Lessons2 is?Ένα όνομα δεν μπορεί να ξεκινά με αριθμό. Ψηφία επιτρέπονται μόνο μετά το πρώτο γράμμα.A name cannot start with a digit. Digits are allowed only after the first letter.

Εκχώρηση και αριθμητικοί τελεστέςAssignment and arithmetic operators

μεταβλητή = έκφρασηvariable = expression

Υπολογίζεται πρώτα η έκφραση δεξιά και η τιμή μπαίνει στη μεταβλητή αριστερά, π.χ. perimetros = 4*plevraThe expression on the right is calculated first and its value goes into the variable on the left, e.g. perimetros = 4*plevra

ΠροτεραιότηταPrecedence

( ) πρώτα, μετά * και /, μετά + και −. Με ίδια προτεραιότητα: από αριστερά προς δεξιά.( ) first, then * and /, then + and −. With equal precedence: from left to right.

+πρόσθεσηaddition
-αφαίρεσηsubtraction
*πολλαπλασιασμόςmultiplication
/διαίρεσηdivision
( )→* /→+ -
