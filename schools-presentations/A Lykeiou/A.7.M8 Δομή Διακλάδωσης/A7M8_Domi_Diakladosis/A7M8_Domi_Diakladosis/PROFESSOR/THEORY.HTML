Η διακλάδωση στο λογικό διάγραμμαBranching in a flowchart

Ο ρόμβοςThe diamond

Μέσα γράφουμε τη συνθήκη: ένα ερώτημα που απαντιέται με Αληθής (True) ή Ψευδής (False).Inside we write the condition: a question answered with True or False.

Μία είσοδος, δύο έξοδοιOne way in, two ways out

Η εντολή if…elseThe if…else command

ΣύνταξηSyntax

if συνθήκη: … else: … Μετά τη συνθήκη και μετά το else βάζουμε άνω-κάτω τελεία (:).if condition: … else: … After the condition and after else we put a colon (:).

Εσοχή (4 κενά)Indentation (4 spaces)

Οι εντολές που ανήκουν στο if ή στο else γράφονται πιο μέσα, όλες με την ίδια εσοχή. Το IDLE τη βάζει μόνο του μετά το :.The commands that belong to if or else are written further in, all with the same indentation. IDLE adds it by itself after the :.

Editor
X = int(input())
Y = int(input())
if X >= Y:
    W = X + Y
else:
    W = X * Y
print(W)

Η print(W) δεν έχει εσοχή: εκτελείται πάντα, μετά τη διακλάδωση.print(W) has no indentation: it always runs, after the branch.

if χωρίς elseif without else

Το else δεν είναι υποχρεωτικόelse is optional

Αν η συνθήκη ισχύει, εκτελούνται οι εντολές του if. Αν δεν ισχύει, δεν γίνεται τίποτα και συνεχίζουμε.If the condition holds, the if's commands run. If not, nothing happens and we carry on.

Απόλυτη τιμήAbsolute value

Αν ο αριθμός είναι αρνητικός, τον πολλαπλασιάζουμε με −1. Αλλιώς τον αφήνουμε όπως είναι.If the number is negative, we multiply it by −1. Otherwise we leave it as it is.

Editor
num = int(input())
if num < 0:
    num = num * (-1)
print(num)

Μπορούμε να την τυπώσουμεWe can print it

Ένα παράδειγμα: τετραγωνική ρίζα ή «Error»An example: square root or “Error”

1 · Δεδομένα → Πληροφορίες1 · Data → Information

Αριθμός N → τετραγωνική ρίζα (riza) ή μήνυμα «Error».Number N → square root (riza) or the message “Error”.

2 · Λογικό διάγραμμα2 · Flowchart

Αν N >= 0 → υπολόγισε και τύπωσε τη ρίζα. Αλλιώς → τύπωσε «Error».If N >= 0 → calculate and print the root. Otherwise → print “Error”.

3 · Πρόγραμμα3 · Program

Ο ρόμβος γίνεται if…else.The diamond becomes if…else.

Editor
N = float(input())
if N >= 0:
    riza = N ** 0.5
    print(riza)
else:
    print('Error')
