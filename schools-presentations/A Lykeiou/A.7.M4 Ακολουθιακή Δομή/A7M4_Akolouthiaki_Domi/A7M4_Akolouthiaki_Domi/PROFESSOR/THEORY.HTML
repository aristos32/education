Τι είναι η ακολουθιακή δομή;What is a sequential structure?

Μία-μία, με τη σειράOne by one, in order

Οι εντολές εκτελούνται η μία μετά την άλλη, από πάνω προς τα κάτω, με τη σειρά που γράφτηκαν. Η καθεμιά εκτελείται μία φορά.The commands run one after the other, from top to bottom, in the order they were written. Each one runs once.

Είσοδος → Επεξεργασία → ΈξοδοςInput → Processing → Output

Τα απλά προγράμματα ακολουθούν αυτό το μοτίβο: διαβάζουμε δεδομένα, κάνουμε υπολογισμούς, τυπώνουμε αποτελέσματα.Simple programs follow this pattern: we read data, we do calculations, we print results.

ΕίσοδοςInputx, y
→
ΕπεξεργασίαProcessingx+y · x*y
→
ΈξοδοςOutputath, gin
x = int(input('Δώσε τον πρώτο αριθμό:'))
y = int(input('Δώσε τον δεύτερο αριθμό:'))
ath = x + y
gin = x * y
print('Άθροισμα=', ath)
print('Γινόμενο=', gin)
x = int(input('Give the first number:'))
y = int(input('Give the second number:'))
ath = x + y
gin = x * y
print('Sum=', ath)
print('Product=', gin)

Η σειρά των εντολών μετράει!NameError: the variable ath has no value yet. The order of the commands matters!

Βήμα 1: Δεδομένα και ΠληροφορίεςStep 1: Data and Information

Δεδομένα (είσοδος)Data (input)

Τι μας δίνει ο χρήστης; Αυτά τα διαβάζουμε με input().What does the user give us? We read these with input().

Πληροφορίες (έξοδος)Information (output)

Τι ζητά το πρόβλημα; Αυτά τα υπολογίζουμε και τα τυπώνουμε.What does the problem ask for? We calculate and print these.

ΕπεξεργασίαProcessing

Οι τύποι που συνδέουν τα δεδομένα με τις πληροφορίες.The formulas that connect the data to the information.

Παράδειγμα: εμβαδόν (Ε = πR²) και περίμετρος (P = 2πR) κύκλου, π = 3.14Example: area (E = πR²) and perimeter (P = 2πR) of a circle, π = 3.14

Βήμα 2: Λογικό διάγραμμαStep 2: Flowchart

Σχεδιάζουμε πριν γράψουμεWe design before we write

Το λογικό διάγραμμα δείχνει τα βήματα της λύσης με σχήματα, από την Αρχή μέχρι το Τέλος.The flowchart shows the steps of the solution with shapes, from Start to End.

Ο κανόναςThe rule

Διάβασε στην αρχή, Τύπωσε στο τέλος, και ανάμεσα η επεξεργασία (εκχωρήσεις ←).Read at the start, Print at the end, and the processing (assignments ←) in between.

💬 ΣυζήτησηDiscussionΣτο διάγραμμα του κύκλου, μπορούμε να βάλουμε το «P ← 2*pi*R» πριν από το «pi ← 3.14»;In the circle flowchart, can we put “P ← 2*pi*R” before “pi ← 3.14”?Όχι: το pi δεν θα είχε ακόμη τιμή. Μπορούμε όμως να αλλάξουμε τη σειρά E και P, γιατί δεν εξαρτώνται το ένα από το άλλο.No: pi would not have a value yet. We can, however, swap E and P, because they don't depend on each other.

Ένα παράδειγμα: περίμετρος ορθογωνίουAn example: perimeter of a rectangle

1 · Δεδομένα → Πληροφορίες1 · Data → Information

Μας δίνουν μήκος και πλάτος → θέλουμε την περίμετρο P.We are given length and width → we want the perimeter P.

2 · Λογικό διάγραμμα2 · Flowchart

Διάβασε → υπολόγισε P = 2 × (μήκος + πλάτος) → Τύπωσε.Read → calculate P = 2 × (length + width) → Print.

3 · Πρόγραμμα3 · Program

mikos = float(input('Μήκος: '))
platos = float(input('Πλάτος: '))
P = 2*(mikos+platos)

Βήμα 4: Έλεγχος με προκαταρκτική εκτέλεσηStep 4: Testing with a trace table

Τιμές που ξέρουμε το αποτέλεσμαValues whose result we know

Ορθογώνιο 5 × 3: περίμετρος 5+3+5+3 = 16. Το πρόγραμμα πρέπει να τυπώσει 16.A 5 × 3 rectangle: perimeter 5+3+5+3 = 16. The program must print 16.

Γραμμή-γραμμήLine by line

Σε κάθε γραμμή γράφουμε την τιμή που παίρνει η μεταβλητή και στο τέλος τι εμφανίζεται.On each line we write the value the variable takes and, at the end, what is displayed.

ΕντολήCommandmikosplatosPΠαρουσίασηOutput

platos = float(input())3
P = 2*(mikos+platos)16
print(P)16.0

Is it a syntax or a logical error?13.0 αντί για 16.0: το πρόγραμμα τρέχει, αλλά δίνει λάθος αποτέλεσμα, άρα λογικό λάθος.
