ΑΡΧΕΙΑ
PROFESSOR/INDEX.HTML – Μενού καθηγητή: ροή 40΄, δείκτες με αντιστοίχιση, απαντήσεις Εμπέδωσης και Kahoot.
PROFESSOR/INTRODUCTION.HTML – Αφόρμηση (5΄): «Κυνήγι λαθών!»: 4 γραμμές κώδικα με ένα λάθος η καθεμιά. Η τάξη ταιριάζει τη διάγνωση με τη γραμμή (κλικ ή σύρσιμο) και ανακαλύπτει τα δύο είδη λαθών: συντακτικά και λογικά.
PROFESSOR/THEORY.HTML – Θεωρία (10΄): 8 διαφάνειες: η Python, το IDLE (Shell και Editor), File › New File / Save As / Open, Run › Run Module, είσοδος–επεξεργασία–έξοδος, συντακτικά λάθη, λογικά λάθη, εντοπισμός και διόρθωση με προκαταρκτική εκτέλεση. Ερώτηση συζήτησης σε κάθε διαφάνεια, χρονόμετρο και εξαγωγή PDF. Βέλη και PgUp/PgDn για αλλαγή διαφάνειας.
STUDENTS/PRACTICE.HTML – Εμπέδωση (10΄), 3 αποστολές για μάθηση:
   1. 🖥️ Γνωρίζω το IDLE
   2. 🐞 Διόρθωσε το A7-M2_p1.py
   3. ➕ Πρόσθεσε τον τρίτο αριθμό Z
   Άμεσος έλεγχος, εξηγήσεις, «Δείξε τη λύση» μετά από λάθος, στατιστικά στο τέλος.
STUDENTS/ASSESSMENT.HTML – Αξιολόγηση (10΄), 3 δραστηριότητες:
   1. 🔍 Κυνήγι λαθών: A7-M2_p2.py
   2. 🧾 Βάλε τις εντολές στη σωστή σειρά: A7-M2_p3.py
   3. 📋 Προκαταρκτική εκτέλεση: A7-M2_p4.py
   Ονοματεπώνυμο και τμήμα στην αρχή. Χωρίς άμεσο έλεγχο και χωρίς λύσεις· μία μικρή υπόδειξη ανά δραστηριότητα (καταγράφεται).
   Μετά την Υποβολή: βαθμολογία ανά δραστηριότητα και κουμπί «Αποθήκευση αποτελεσμάτων (HTML)» με όλες τις απαντήσεις (✓/✗). Αν τελειώσει ο χρόνος, γίνεται αυτόματη υποβολή.

ΣΥΝΟΨΗ (5΄) – Κλείδωμα υπολογιστών μέσω NetSupport, προφορική ανάκληση των δεικτών επιτυχίας και Kahoot 4 ερωτήσεων (το πλήρες Kahoot 10 ερωτήσεων για επανάληψη). Στο εργαστήριο: τα αρχεία A7-M2_p1…p4.py του φακέλου M2.
