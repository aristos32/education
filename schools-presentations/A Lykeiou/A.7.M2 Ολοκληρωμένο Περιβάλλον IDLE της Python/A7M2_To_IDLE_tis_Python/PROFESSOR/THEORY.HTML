Η γλώσσα προγραμματισμού PythonThe Python programming language

Ποιος τη δημιούργησε;Who created it?

Ο Ολλανδός Γκίντο βαν Ρόσσουμ (Guido van Rossum) στο ερευνητικό κέντρο CWI το 1989. Κυκλοφόρησε για πρώτη φορά το 1991.The Dutch programmer Guido van Rossum at the CWI research centre in 1989. It was first released in 1991.

Γιατί Python;Why Python?

Εύκολη σύνταξη, πολλές βιβλιοθήκες, γρήγορη εκμάθηση. Είναι δημοφιλής στη διδασκαλία και στο ανοικτό λογισμικό.Easy syntax, many libraries, quick to learn. It is popular in teaching and in open-source software.

Νέο, Αποθήκευση, ΆνοιγμαNew, Save, Open

Το μενού FileThe File menu

Όλες οι εργασίες με αρχεία γίνονται από το μενού File.All work with files is done from the File menu.

Επέκταση .pyThe .py extension

Τα αρχεία της Python πρέπει να έχουν επέκταση .py, π.χ. athroisma.pyPython files must have the .py extension, e.g. athroisma.py

File › New FileΑνοίγει νέο, κενό παράθυρο Editor για να γράψουμε κώδικα.Opens a new, empty Editor window to write code.
File › Save AsΑποθηκεύουμε με όνομα και επέκταση .py.We save with a name and the .py extension.
File › SaveΑποθηκεύουμε τις αλλαγές στο ίδιο αρχείο.We save the changes to the same file.
File › OpenΑνοίγουμε ένα υπάρχον αρχείο σε παράθυρο Editor.We open an existing file in an Editor window.
💬 ΣυζήτησηDiscussionΓράψατε ένα πρόγραμμα αλλά κλείσατε το παράθυρο χωρίς Save. Τι έγινε;You wrote a program but closed the window without saving. What happened?Το πρόγραμμα χάθηκε (το IDLE συνήθως ρωτά πριν κλείσει). Αποθηκεύουμε συχνά, πάντα με επέκταση .py.The program is lost (IDLE usually asks before closing). We save often, always with the .py extension.

Συντακτικά λάθηSyntax errors

Τι είναι;What are they?

Παραβιάσεις του συντακτικού της γλώσσας. Το πρόγραμμα δεν εκτελείται μέχρι να διορθωθούν.Violations of the language's syntax. The program cannot run until they are fixed.

Λογικά λάθηLogical errors

Τι είναι;What are they?

Το πρόγραμμα τρέχει, αλλά δίνει λάθος αποτέλεσμα ή σταματά απρόβλεπτα. Είναι δύσκολα στον εντοπισμό.The program runs, but gives a wrong result or stops unexpectedly. They are hard to find.

Πώς τα βρίσκουμε;How do we find them?

Δοκιμάζουμε με τιμές για τις οποίες ξέρουμε ήδη το σωστό αποτέλεσμα.We test with values whose correct result we already know.

athroisma.py · Editor
number1=int(input('1: '))
number2=int(input('2: '))
sum=number1-number2
print(sum)
Shell
1: 6
2: 8
-2
# αναμέναμε 14!we expected 14!

Το πρόγραμμα υπολογίζει τη διαφορά και όχι το άθροισμα.The program calculates the difference, not the sum.

💬 ΣυζήτησηDiscussionΓιατί η Python δεν εμφανίζει μήνυμα λάθους εδώ;Why doesn't Python show an error message here?Γιατί η εντολή είναι συντακτικά σωστή. Η Python δεν ξέρει τι θέλαμε να υπολογίσουμε· το λάθος το βρίσκουμε εμείς με δοκιμές.Because the command is syntactically correct. Python doesn't know what we wanted to calculate; we find the mistake ourselves by testing.

Εντοπίζω και διορθώνωFind and fix

Ο κύκλος διόρθωσηςThe fixing cycle

Εκτελώ → διαβάζω το μήνυμα ή ελέγχω το αποτέλεσμα → διορθώνω → αποθηκεύω → ξανατρέχω.Run → read the message or check the result → fix → save → run again.
