📖 Πώς…; Μορφοποίηση Κειμένου στο PowerPoint

🎵 «Μουσικό Φεστιβάλ» · Βρείτε γρήγορα πώς γίνεται κάθε βήμα του φύλλου εργασίας. Οι ετικέτες Εμπ. / Αξ. / Επ. δείχνουν τα βήματα όπου χρειάζεται.

📂Πώς ανοίγω και κλείνω μια παρουσίαση;

File › Open › Browse
  1. Πατάω File › Open (ή Ctrl+O).
  2. Βρίσκω τον φάκελο με το ΥΛΙΚΟ.
  3. Επιλέγω το αρχείο (π.χ. Music.pptx) → Open.
❌ Κλείσιμο: File › Close ή Ctrl+W.
Φύλλο:Εμπ. 1–2Αξ. 1Επ. 1

⌨️Πώς γράφω ή αλλάζω κείμενο;

  1. Κάνω κλικ μέσα στο πλαίσιο κειμένου της διαφάνειας.
  2. Πληκτρολογώ το κείμενό μου.
  3. Αντικατάσταση: επιλέγω τη λέξη/φράση και γράφω από πάνω της.
🎵 π.χ. «Classical Music» → «Κλασική Μουσική», «Omada 1» → «Ομάδα 1».
Φύλλο:Εμπ. 3Αξ. 2–4

🖱️Πώς επιλέγω και διαγράφω κείμενο;

  1. Κλικ στο πλαίσιο και σέρνω το ποντίκι πάνω στο κείμενο.
  2. Διπλό κλικ = μία λέξη · τριπλό κλικ = όλη η παράγραφος.
  3. Για διαγραφή: επιλέγω και πατάω Delete.
💡 Πρώτα επιλέγω, μετά μορφοποιώ — ισχύει για όλες τις εντολές!
Φύλλο:Εμπ. 3–6Αξ. 2, 5

🔤Πώς αλλάζω γραμματοσειρά και μέγεθος;

Home › Font
Tahoma ▾20 ▾
  1. Επιλέγω το κείμενο.
  2. Βελάκι στο Font → διαλέγω γραμματοσειρά (π.χ. Tahoma).
  3. Βελάκι στο Font Size → διαλέγω μέγεθος (π.χ. 20).
💡 Αν το μέγεθος δεν υπάρχει στη λίστα, το πληκτρολογώ και πατάω Enter.
Φύλλο:Εμπ. 5α, 6Αξ. 2

🅱️Πώς βάζω έντονη, πλάγια, υπογράμμιση, σκιά;

Home › Font
BIUS
  1. Επιλέγω το κείμενο.
  2. Πατάω: B έντονη Ctrl+B · I πλάγια Ctrl+I · U υπογράμμιση Ctrl+U · S σκιά.
  3. Για αφαίρεση: ξαναπατάω το ίδιο κουμπί.
🎵 Εμπ. 4: Bold μόνο στις λέξεις πριν από την άνω και κάτω τελεία ( : ).
Φύλλο:Εμπ. 4, 5β–γΑξ. 5

🎨Πώς αλλάζω χρώμα κειμένου;

Home › Font › A ▾
A▾
  1. Επιλέγω το κείμενο.
  2. Κλικ στο A = το χρώμα που φαίνεται από κάτω.
  3. Για άλλο χρώμα: βελάκι ▾ δίπλα στο A → διαλέγω από την παλέτα.
🎨 Δικό μου χρώμα: ▾ → More Colors… → καρτέλα Custom → γράφω Red, Green, Blue → OK.
Φύλλο:Εμπ. 5δ, 6Αξ. 5Επ. 3

↶Πώς αναιρώ (Undo) και επαναφέρω (Redo);

Γρήγορη Πρόσβαση (πάνω αριστερά)
↶↷
  1. Αναίρεση (Undo) ↶ ή Ctrl+Z: ακυρώνει την τελευταία ενέργεια.
  2. Ακύρωση Αναίρεσης (Redo) ↷ ή Ctrl+Y: επαναφέρει ό,τι αναίρεσα.
🎵 Εμπ. 7–8: πατάω Undo 2 φορές (σβήνουν Tahoma + μπλε), μετά Redo 2 φορές (επανέρχονται).
Φύλλο:Εμπ. 7–8

▶️Πώς προβάλλω την παρουσίαση;

Slide Show › From Beginning / From Current Slide
  1. Από την αρχή: From Beginning ή F5.
  2. Από συγκεκριμένη διαφάνεια: κλικ πρώτα σε αυτήν (π.χ. 3η) → From Current Slide ή Shift+F5.
  3. Επόμενη: →/κλικ · Προηγούμενη: ← · Τέλος: Esc.
Φύλλο:Εμπ. 9–10Αξ. 6Επ. 5

💾Πώς αποθηκεύω με άλλο όνομα;

File › Save As › Browse · F12
  1. File › Save As (ή F12).
  2. Επιλέγω τον φάκελό μου.
  3. Γράφω το νέο όνομα στο File name (π.χ. M1_music) → Save.
💡 Save As = νέο αντίγραφο, το αρχικό μένει ανέπαφο · Save (Ctrl+S) = γράφει στο ίδιο αρχείο.
Φύλλο:Εμπ. 11Αξ. 7Επ. 6

➕Πώς κάνω διπλή υπογράμμιση ή διακριτή διαγραφή;

Home › Font › ↘ (μικρό βελάκι κάτω δεξιά)
  1. Επιλέγω το κείμενο και ανοίγω το παράθυρο Font από το ↘.
  2. Underline style → διπλή γραμμή · Underline color → κόκκινο.
  3. Strikethrough ☑ → Παγκράτιο → OK.
Αποτέλεσμα: διπλή κόκκινη υπογράμμιση · διακριτή διαγραφή
Φύλλο:Επ. 2, 4
